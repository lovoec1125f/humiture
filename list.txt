方案：STM32F103C8 + FreeRTOS 多任务温湿度监测系统
一、项目描述
基于 STM32F103C8T6 与 FreeRTOS 实时操作系统，开发多任务温湿度监测系统。系统通过单总线协议采集 DHT22 温湿度传感器数据，经队列传递至显示与报警任务，实现 OLED 实时显示、超限声光报警；支持按键与串口上位机两种方式配置报警阈值，代码使用 Git 进行版本管理。

技术栈修正：原描述里「I2C 采集传感器」是错的，DHT22 是单总线；I2C 现在用于 OLED 显示；SPI 无器件，已去掉。
最终技术栈：STM32F103C8、C语言、HAL库、FreeRTOS、单总线(DHT22)、I2C(OLED)、USART、队列、互斥锁、信号量、Git

二、硬件清单与接线
模块	型号	接线
主控	STM32F103C8T6 最小系统板	—
传感器	DHT22 (AM2302)	DATA → PB12
显示	0.96" OLED SSD1306 (I2C)	SCL→PB6、SDA→PB7（I2C1）
报警	有源蜂鸣器	I/O → PB0
指示灯	LED（板载）	PC13
串口	CH340 USB-TTL	TX→PA9、RX→PA10（USART1）
按键	轻触按键（上拉）	→ PA0（EXTI0）
三、系统架构
任务划分：

任务	优先级	周期	职责	用到的 RTOS 机制
SensorTask	高	2s	读 DHT22 → 入队	队列(发)、临界区
DisplayTask	中	事件驱动	出队 → OLED 显示	队列(收)
AlarmTask	中	500ms	判断阈值 → 声光报警	互斥锁(读阈值)
CmdTask	低	事件驱动	串口命令解析/回传	互斥锁(写阈值)、USART
KeyTask	低	事件驱动	按键消抖 → 调阈值	信号量(EXTI唤醒)、互斥锁(写阈值)
数据流：


DHT22 ─单总线→ SensorTask ─队列→ DisplayTask ─I2C→ OLED
                        └─队列→ AlarmTask ─GPIO→ 蜂鸣器/LED
串口 ─USART→ CmdTask ─互斥锁→ [阈值参数] ←互斥锁─ KeyTask ←信号量─ 按键(EXTI)
三个 RTOS 机制的具体用途（答辩亮点）：

队列：采集与显示/报警解耦，生产者-消费者模型。
互斥锁：阈值参数同时被 CmdTask/KeyTask 写、AlarmTask 读，防数据竞争。
信号量：按键 EXTI 中断发二值信号量，唤醒 KeyTask 消抖处理（不用在 ISR 里做事）。
四、功能需求（验收标准）
采集：每 2s 读一次，温度 0.1℃、湿度 0.1%RH，校验和失败要重试。
显示：OLED 两行显示温湿度 + 报警状态。
报警：温度或湿度超阈值 → 蜂鸣器响 + LED 闪；恢复自动解除（带回差，防临界抖动）。
按键：短按切换设置项（温度上限/湿度上限/退出），长按数值+1。
串口：查询数据、设阈值、开关报警。
五、串口命令协议（115200-8-N-1）
命令	功能
READ	回传当前温湿度
SET TH 30.0	设温度上限
SET HH 70.0	设湿度上限
ALM ON/OFF	开关报警
